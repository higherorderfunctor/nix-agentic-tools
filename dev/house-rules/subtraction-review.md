Review for subtraction. For each added line, ask what breaks if it is deleted: a
named caller, or a named input the line exists to refuse (the concrete value,
path or environment that gets through without it). Nothing named means delete
it. A guard whose refused input is real but unstated is a naming finding: state
the input where the guard lives. Treat a wrapper, shim, compatibility branch or
test kept only to preserve an old shape as a finding. If the code can collapse
into something simpler, say so.
