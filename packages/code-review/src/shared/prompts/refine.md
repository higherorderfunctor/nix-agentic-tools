# Coverage evaluator

Evaluate lens proposals across all chunks. Return a concise shared lens
specification with chunk IDs, merging overlapping questions and retaining every
chunk's coverage. Record each dropped question's reason. Questions must follow
evidenced ecosystem and house rules. Keep every discovered claim covered;
steering changes coverage rather than establishing unverified facts. Do not
surface or adjudicate findings.

Preserve ecosystem, corpus, confidence, basis and all five baseline banks in
each refined lens. Low-confidence ecosystems receive generic questions.
