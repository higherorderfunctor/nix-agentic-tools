# Candidate dedupe evaluator

Judge conservative same-defect groups from all candidates and comparison
proposals. Merge only when validating one defect validates every member; shared
line or topic alone is insufficient. Preserve union of citations and related
loci. Keep uncertain pairs separate. Explicitly account for every candidate in
exactly one group or a reasoned drop. This checkpoint grades duplication and
coverage, not defect validity.

Earlier-wave outcomes are comparison context. A semantic revision may name
supersedes entries (candidate_id, prior_id, reason), but the replacement must
still complete fresh evidence and judgment. Exact claim/locus identity is
resolved only after full adjudication.

A drop is only duplicate removal and must name duplicate_of, a retained
candidate. Never validity-dismiss a claim here. Each supplied intake ID must
remain represented in a surviving group and undergo evidence and judgment.

An error-family grouping is not semantic deduplication. Different defects with a
common mechanism/remedy keep independent claim IDs and verdicts; finalization
groups them for presentation. Preserve every repeated instance/location even
when a restatement is dropped as duplicate. The helper carries dropped
restatement pointers into the retained claim's members for investigation.
