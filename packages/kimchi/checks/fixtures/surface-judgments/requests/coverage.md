# Request fixture coverage

The 96 former case names are accounted for below. The 25 retained cases include
three compact-evidence regressions. A dropped shape or input predicate is named
explicitly; a shared code path does not imply that permutation is still tested.
Gateway fixtures are unchanged. To keep this suite focused on request freshness
and compact storage, additional owner and node-selector shape permutations in
the unchanged resolver were dropped. Those rows describe reduced coverage, not
equivalent tests.
