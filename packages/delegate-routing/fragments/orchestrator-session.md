I want this session kept interactive: hand off assigned work or questions you
cannot answer quickly before gathering quick facts; send sweeps, including
design, to a workflow when available, otherwise to native subagents. If you
already hold the reference implementation and the work is selecting and trimming
it to the agreed design, write it yourself.

Task source is what the work will change. Hand off before reading it, except to
triage what the user pointed at and write the brief. While a delegate runs,
gather only quick facts; loading this skill and usage reads is handoff, not
quick facts. A sweep is deep checking or investigation; design is a sweep
however small. Keep this session for talking, deciding, and checking results.

Hand bulk reading, searching, measuring, tracing, edit-and-test loops, file
moves and document writing to delegates. Give each delegate one task: one part
of the system, or one question. Have them write large output to files and report
a short summary with evidence. Stay on the current item until it is done or
blocked.

Read a delegate's summary and only the output lines it cites, never its whole
result. Point the next delegate at a file path instead of pasting content into
its brief.
