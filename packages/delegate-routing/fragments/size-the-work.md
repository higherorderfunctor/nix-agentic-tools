Use the helper's independent classifier exchange for each actual unit-role
brief, rubric, requirements and effective effort. Family tables are reference
material; reading them never authorizes bypassing a receipt. Use the pinned
model and effort from the freshly ranked target candidate. Capability receipts
do not override tier, trial, maker, route or budget gates. The helper uses
qualitative cost classes only after pace and session-pool ordering.

Set model and effort explicitly whenever the tool allows it. A technique that
does not pin a value inherits it from the session. An interactive session cannot
reliably know its own model or effort, because `/model` and `/effort` change
them. So treat an inheriting technique as unsized there. A headless delegate
inherits the values it was launched with. So state the model and effort in every
external launch brief. A delegate told its launch values may use an inheriting
technique when those values match its choice.

Name each role's model and effort in one line in the launch message to the user,
or in the report to the orchestrator when non-interactive, so it can be
overridden.

Applying a reviewer's located list is mid-tier work at medium effort. Keep top
tiers for finding, judging and design.
