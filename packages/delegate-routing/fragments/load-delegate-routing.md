Load the delegate-routing skill in the turn you hand work to a subagent, another
CLI or a workflow. Every delegation gets its own load; a load from an earlier
turn does not carry over. It lists the models and tools you can use, and how to
set model and effort for each. Delegate-routing owns these delegation and review
rules. When someone steers how they should work, propose a change here so it is
committed and distributed; do not record that steering in memory or as a house
rule that changes how the skill is read.
