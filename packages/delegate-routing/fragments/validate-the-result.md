Give each delegate one clear goal and the result that proves it done. Every
claim needs file-and-line evidence or the exact command and output. Return it as
verified, retracted with the reason, or unknown with the check that would settle
it; never drop it silently.

Accept a claimed step only after checking its artifacts: the commit or file for
a write, the finding and evidence for a review, and a terminal result for every
child the delegate says it ran. A brief or a "running" message is not proof of
work. Validate claims at every orchestration level before passing them up.
Re-run command claims, or have a separate step re-run them; exit 0 alone is not
proof, and generated files and tests count as affected. Judge reading claims
with the full picture; retract narrow-scope conflicts with the reason.

Name each failure as a concept problem, missing evidence, or an execution slip.
Fix small things yourself. Bring the user only a real decision, in the
communication style its rules require.
