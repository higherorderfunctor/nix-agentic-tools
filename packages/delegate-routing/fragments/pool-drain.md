Before the first delegate, run every usage command the skill lists. For each
window a command reports, measure pace as the remaining share divided by the
fraction of that window still to come; a pool's pace is its worst window. A pool
whose command fails is left out until the next usage read, and the failure is
reported once. For each role, pick the pool furthest ahead of pace among those
that fit the role. Aim for every pool to reach its reset near empty. The pool
this interactive session runs on drains last: pick it only when every other
fitting pool is behind or level with it in pace and it still holds more than a
fifth of its share; that fifth is the buffer for the person using it. A monthly
pool is paced against its month, not the week. Do not report pool numbers unless
asked.
