# Kimchi delegate replays

Pins, evidence marks and case-prefix meanings:
[evidence guide](../../../docs/delegates/evidence.md).

Every script runs the repository's pinned `kimchi` and `kimchi-workflows` (built
on demand; `KIMCHI_PKG` / `KIMCHI_WORKFLOWS_PKG` skip the build) and reads the
pinned sources (`kimchi.src`, `kimchi.extractionSources.pi`,
`kimchi-workflows.src`). Scratch output goes to `$PROBE_OUT/<name>` when set,
otherwise to a fresh temp dir that the script prints.

All cases are **OFFLINE**: a fresh HOME/XDG tree, a fake API key and a fake
gateway (`live/fakeprov.py`) on 127.0.0.1; `OLLAMA_HOST` points at a dead port.
One exception to "no network": `/workflow run` (the `w*` scenarios) lets
kimchi-workflows provision `.kimchi/workflows/` with pnpm, which may reach the
npm registry. No model provider is contacted.

## Harness

| File                              | Role                                                                                                                                                                                                                                                                                                     |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `live/drive.py <sc.json> [<out>]` | Builds the isolated HOME and `config.json` (`llmEndpoint` = fake), optional workflows link, project files; runs the pinned binary; feeds timed RPC/ACP stdin lines; auto-allows ACP permission requests; cancellation fixtures wait for the active step provider request and log sends in `stdin.jsonl`. |
| `live/fakeprov.py`                | Fake gateway: `/v1/models/metadata` (fake-a, fake-b) and `/openai/v1/chat/completions` (SSE). A request offering `Agent` is the parent and follows `PLAN=…`; others are children (`SLEEP=n`, `CHILDPLAN=…`, `WFSLEEP=n`). Logs `provider.jsonl`.                                                         |
| `live/summ.py <out>`              | Wire summary: role, model, `reasoning_effort`, delegate tools, markers.                                                                                                                                                                                                                                  |
| `live/all.sh [<name>…]`           | Runs every (or the named) scenario and writes `summary.txt` beside each.                                                                                                                                                                                                                                 |
| `inv/run.sh <label> [args]`       | Tool inventory: `observer.ts` prints every registered tool and command at the first input event and swallows it (no model call).                                                                                                                                                                         |
| `codex-side/offline.py <case>`    | Codex-side scripted-gateway cases.                                                                                                                                                                                                                                                                       |
| `codex-side/node.sh <script.cjs>` | Runs a Codex-side TypeScript-AST/VM script with `TYPESCRIPT_JS`, `KIMCHI_SRC`, `PI_SRC`, `KIMCHI_WORKFLOWS_SRC` set; output JSON goes to the current directory.                                                                                                                                          |

### Judge source replay

| Case id  | Command                   | Expected excerpt                                                                |
| -------- | ------------------------- | ------------------------------------------------------------------------------- |
| judge:J3 | `python3 resume_guard.py` | `record.taskRef?.kind === "ferment_step" && attemptsForPurpose >= attemptLimit` |

J3 is source evidence (A), not a wire execution. The ordinary-agent continuation
execution is separately indexed as `codex:B`. `KIMCHI_SRC` may point at an
already materialized pinned source for this source-only replay.

RPC and ACP drivers stay open until the scenario deadline. Their `meta.json`
timeout and termination code are cleanup, not a failed behavior assertion;
inspect the wire, tool results and session files. The inventory resolves its
stdin fixture before entering the scratch project. Native AST extraction
requires every selected declaration, and its VM replay reads the exclusion
constants from the pinned source.
