Every way a delegate starts, per harness, then one cross-harness comparison.

Pins: Claude Code 2.1.289 · Codex CLI 0.160.0 · Kiro CLI 2.27.1 (KAS 0.66.22;
default engine v2) · Kimchi 1.5.1 / Pi 0.85.1 / kimchi-workflows 0.0.9.

Marks: **V** executed · **A** AST · **G** grep · **I** inferred · **U** unknown
· **SPLIT** sides disagree (none remain).

Replay: a case id `<side>:<case>` resolves under
`packages/delegate-routing/probes/delegates/<harness>/`. The prefix is the probe
side (`claude`, `codex`, `judge`), not the harness.
